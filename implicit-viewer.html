Implicit Field Viewer¶

Every socket we design in nTop is an implicit: not a mesh, but a function that gives the signed distance to the surface at any point in space. The viewer below renders that function directly. Drag to orbit, scroll to zoom, and move the sliders: the wall offset, the section cut, and the lattice are all computed live in your browser, not swapped in from pre-made files.

Making a field from an nTop export¶

The viewer reads .sdf files: a sampled signed distance field, about half a megabyte per model. You make one from any watertight mesh export, which is what nTop already produces:

  1. In nTop, export the implicit body as a mesh: STL, OBJ, PLY or 3MF from the Export Mesh block. Any of the site's existing .glb models work too.
  2. Run the bake script, which samples the signed distance onto a grid: 
    python tools/bake_sdf.py my-socket.stl --res 160 --name "My socket"
    --res is the number of voxels along the longest axis. 160 gives roughly 1.4 mm per voxel on a socket and a 0.5 MB file; 200 is finer and about twice the size.
  3. Drop the resulting .sdf onto the viewer above to check it, then commit it to the repository and add it to the model list in this page.

A field captures one shape, so operations that change the shape itself (a different lattice point count, a new scan) need a new bake. Everything the sliders above do is computed from the field at render time.
