What the checks mean

Wrong units are not a defect but the most common surprise: a 200 mm socket that shows up as 0.2 was exported in metres (scanners, Blender). The file details line flags sizes like that; set the unit when you import into nTop. Order matters: the checks run in the order above, because welding split vertices first clears most open-edge and non-manifold reports. Repairs never move a vertex that was not already on top of another one. The self-intersection check is the slow one and stops at the time limit in Repair settings. For meshes this cannot fix, nTop's own route usually works: Mesh to Implicit, Boolean the bodies there, then Implicit to Mesh.
