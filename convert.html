3D model converter

Turn an STL, OBJ, 3MF or GLB into a small GLB you can drop into a presentation, the design review page or PowerPoint. Everything happens in your browser; nothing is uploaded. Mesh not importing into nTop? Run it through the mesh check & repair tool first.

Using the file

PowerPoint

Use Download GLB (the plain file; PowerPoint cannot read the compressed one). Insert → 3D Models → This Device, pick the GLB. It turns on the slide and plays a slow spin if you add the Turntable animation. Keep to the Presentation setting; PowerPoint struggles past a few hundred thousand triangles.

Design review page

On any review, Add files at the top loads either GLB for your own session. To put it in a presentation for good, hand the website file (and the deck file from here, if you made one) to whoever runs the editor; the editor's media gallery copies it into the site.

Any web page

Both files are standard glTF binaries; the website one adds Draco compression, which <model-viewer>, three.js and Babylon all decode. The site's viewers expect Z up in millimetres, which is what this writes.

Converting a whole nTop sweep into a slider? Use Sweep Studio instead; it plans the sweep, converts every file and writes the slider for you.

Presentation keeps about 150,000 triangles, the setting every model on this site uses; Full keeps all of them. Use Compare quality levels to see both on your own model before deciding. Conversion runs in your browser with three.js, meshoptimizer and gltf-transform; large files take a few seconds and some memory.
