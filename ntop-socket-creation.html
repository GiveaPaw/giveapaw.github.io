nTop Socket Creation¶

Our custom nTop workflow turns a cleaned 3D scan into a printable lattice prosthetic. This page documents each block in the workflow: what it does, the inputs you can change, and an interactive demo of how each input reshapes the socket and the paw.

The same parameter value produces very different geometry on different animals - a Max Socket Thickness of 8 mm dominates a Chihuahua socket but is a modest wall on a German Shepherd. Pick an animal below; every demo on this page then shows that animal's model library.

Socket Lattice¶

The Socket Lattice block converts the solid socket shell into a flexible lattice that can bend with the animal's residual limb while staying strong enough to carry load. Below is the block as it appears in nTop.

Tip: Click any input on the block to expand its live demo. Each demo changes one input while the others stay at their defaults, so the difference you see comes from that parameter alone. Drag the model to rotate it, scroll to zoom, and use the view cube to snap or step the orientation.

▾ CB - Socket Lattice

Socket & Interface Cap¶

The Interface Cap block joins the lattice socket to the mechanical socket. It takes the Socket Lattice output as its input and positions, angles, and blends the rigid interface. Click any input to explore its sweep; the blend point demos are shown with the blend radii fixed at 20 / 5 mm so the moving blend is easy to see.

▾ Socket & Interface Cap
mesh Solid, Socket: Socket Lattice
mesh Mech, Solid: Mech, Solid
xyz Lateral Rotation Axis: -57.42, -82.51, 165.59 mm

Attachment¶

The Attachment block adds the screw pads and holes that fasten the finished socket to the animal. It takes the Socket & Interface Cap output as its input. Click any input to explore its sweep, and toggle the Attachment Point Spheres to see the six fastening points on the socket.

▾ CB - Attachment
mesh Socket, Solid Animal: Socket & Interface Cap
xyz Attachment Points: Attachment Points mm
